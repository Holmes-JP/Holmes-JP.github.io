MEMORY サポートプライバシーポリシー

プライバシーポリシー

MEMORY ／ 制定日・最終更新日：2026年9月13日

開発者 -Monad-（以下「運営者」）は、記憶ゲーム「MEMORY」（以下「本アプリ」）と本サポートサイトにおける情報の取り扱いを、以下のとおり定めます。

1. ゲームの設定と記録

サウンド・振動の設定、カスタムゲームの条件、自己ベスト、遊び方の確認状態、広告表示頻度の管理情報を端末内に保存し、ゲームの提供と設定・記録の維持に使用します。現在のゲーム機能にアカウント登録や運営者のサーバーへの記録同期はありません。

端末内のデータは、OSのアプリデータ削除機能またはアプリの削除で消去できます。バックアップからの復元などの取り扱いは、OSや利用するサービスの設定によって異なります。

2. 広告と同意設定

本アプリはGoogle AdMobによる広告配信と、広告に関する同意・選択を管理するUser Messaging Platform（UMP）を使用します。

広告SDKは、広告の配信・測定・分析、不正利用の防止、動作の診断のため、IPアドレスとそこから推定されるおおよその地域、端末・アプリ等の識別子、アプリや広告の操作情報、診断・性能情報を取得・送信する場合があります。広告識別子などの利用は、OSの権限、端末設定、利用者の選択および配信設定により異なります。

地域と同意の状態に応じて、広告に関する選択画面を表示します。設定を変更できる場合は、タイトル画面の「広告・プライバシー」から「広告の同意設定」を開けます。OSが提供する広告・プライバシー設定も利用できます。同意の選択によって広告の種類や有無が変わる場合がありますが、ゲーム機能や自己ベスト保存の利用を広告への同意の条件にはしません。

Googleによる情報の保存・利用・削除については、GoogleプライバシーポリシーとGoogleの広告に関する説明をご確認ください。

3. 未成年の利用

未成年の方は、必要に応じて保護者と本ポリシーや端末のプライバシー設定をご確認ください。広告の内容には全年齢向けの上限を設定しています。この設定は利用者の年齢確認を行うものではありません。子どもの情報の取り扱いに関するご相談は、下記の窓口へご連絡ください。

4. お問い合わせとサイト閲覧

お問い合わせの際に受け取るメールアドレス、氏名、本文、任意の添付資料は、回答、問題の調査、サポート履歴の管理に使用します。メール窓口にはGmailを使用します。回答に不要な個人情報は送らないでください。

本サイトはGitHub Pagesで配信します。GitHubはセキュリティ等の目的でアクセス元IPアドレス等を記録する場合があります。本サイトに独自のアクセス解析タグ、広告タグ、入力フォームは設置していません。GitHubのプライバシーステートメントをご確認ください。

5. 情報の管理とお問い合わせ

運営者が取り扱う情報の開示・訂正・削除・利用停止等をご希望の場合は、下記の窓口へご連絡ください。必要に応じて本人確認を行い、適用される法令に従って対応します。法令上または対応の継続に必要な記録は、直ちに削除できない場合があります。外部サービスが取り扱う情報については、そのサービスの窓口や設定もご利用ください。

運営者の氏名・名称や所在地など、事業者情報に関する照会も同じ窓口で受け付けます。

6. 本ポリシーの変更

機能や外部サービス、情報の取り扱いの変更に応じて本ポリシーを改定します。重要な変更は本サイトまたはアプリ内でお知らせし、必要な場合は同意を取得します。
