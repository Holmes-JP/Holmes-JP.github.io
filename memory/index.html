MEMORY

光った場所を覚えて、消えたらタップする記憶ゲーム。

遊び方

黄色く光るタイルの位置を覚え、光が消えてから同じ場所をすべてタップします。通常モードは5ラウンド。カスタムモードでは練習用の条件を選べます。

広告について

通常ゲーム終了後の画面切り替え時に、間隔を空けて広告を表示します。記憶中・回答中・カスタム練習中には表示しません。広告に関する設定は、タイトルの「広告・プライバシー」から確認できます。
